Timed Hardcore turns hardcore multiplayer into something you can actually play with friends. When you die, you are not gone for good. You are locked out of the server for a configurable time or until the next fixed revival time of the day.

- Rejoining shows how long you are still dead, and so does the server list.
- You are safe while enough players are online, so dying only counts when you play alone.
- A rare Wandering Healer sells the green apple, which grants one extra life.
- Operators can revive players at any time with a command.
- The mod runs on the server. Installing it on the client is optional and adds live heart colors that show what happens if you die right now.
